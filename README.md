
# PLD Plume – Blender Scene

A 3D visualization of pulsed laser deposition (PLD): a laser strikes an oxide
target inside a vacuum chamber, and the resulting plasma plume expands toward
the substrate, where a thin film is deposited.

![PLD plume](render/PLDplume_particles%20hidden.png)

## Contents

- `PLD_plume.blend` – the Blender scene
- `render/` – example rendered images

## Requirements

You need [Blender](https://www.blender.org/download/) (free) to open or modify
the scene. It was created with Blender 5.1; older versions may not open it
correctly.

## Usage

Open `PLD_plume.blend`, select the scene named `PLD`, and press F12 to render.
The scene uses the Cycles render engine.
